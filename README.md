# Ağıllı Taksi Dispetçeri (planlaşdırılır)

Bakı xəritəsi üzərində real-vaxt taksi dispetçerlik simulyasiyası — JEV (TypeSafe System One) modelinin Choice/Score/Noul primitivləri ilə sürücü təyinatı, təcililik qiymətləndirməsi və saxta sifariş aşkarlanmasını nümayiş etdirir.
